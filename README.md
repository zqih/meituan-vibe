# 今天吃哪口 · 校园食堂点评推荐

校园食堂点评推荐工具的可交互体验版。采用清爽雾蓝配色、统一中文字号与清晰的筛选状态，支持桌面和手机访问。

## 访问网站

https://zqih.github.io/meituan-vibe/

## 页面文件

`index.html` 为入口，`style.css` 提供响应式样式，`app.js` 处理交互，`data.js` 存放示例数据。无需安装依赖或构建，直接用静态服务器预览。`DESIGN.md` 记录颜色、字号、控件和交互规范。

## 已实现

- 按食堂、菜品类型、预算筛选，搜索菜名、窗口和标签；筛选条件同步到 URL，支持刷新和后退恢复。
- 快捷条件显示选中状态，再次点击可取消；收藏操作保留卡片和键盘焦点。
- 口碑榜、低分菜品提醒、上新、预算与快速出餐快捷入口。
- 菜品详情、具体点评、价格、辣度和预计等待时间。
- 收藏，保存与删除本机点评；刷新后保留。
- 按预算、辣度、食堂从4分以上菜品中随机选餐，连续选择时尽量不重复。
- 键盘操作、弹窗、空结果提示与浏览器存储失败提示。

## 演示范围

南湖大学、三个食堂、窗口、12道菜品的价格、评分、等待时间和点评均为虚构示例。照片仅为食物示意，并非对应菜品实拍。当前没有共享后端，新增点评和收藏仅保存于当前浏览器，不跨设备、不对其他访客公开。
